## 💡 Why FireWeb?

> A messenger built for people who refuse to lose their voice.

| ⚡ Scenario | 🔥 FireWeb Response |
|:---|:---|
| 🚫 Internet censorship | We don't care. Stay connected. |
| 🌐 Network outage | Chat via local intranet, no internet needed. |
| 🔒 Privacy concerns | Your server, your data. Zero third-party. |
| 🛠️ Complex setup? | **3 minutes. Seriously.** |

## 🚀 Quick Start

```bash
git clone https://github.com/PRGPU/FireWebCHAT.git
Upload project files to your server (any shared hosting works) bash
```

Open setup helper → firewebchat.vercel.app

Watch the full tutorial → youtu.be/Z_BUtrt-Trc (optional)

Visit your domain → setup wizard auto-starts 🎉

text
https://yourdomain.com/
✅ Done in 3 minutes. No composer. No npm. No Docker.
