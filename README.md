## 🔥 What is FireWeb?

> **A freedom-first messenger. Self-hosted, encrypted, unstoppable.**  
> When the internet shuts down — FireWeb keeps you connected via local intranet.  
> No cloud. No tracking. No compromise.

<br/>

## ⚡ Why FireWeb?

<div align="center">

|  | Scenario | FireWeb |
|:---:|:---|:---|
| 🚫 | Internet censored | Stay connected, we don't care |
| 🌐 | Network outage | Run on local intranet, zero internet needed |
| 🔒 | Privacy matters | Your server, your data, zero third-party |
| ⚡ | Hard to setup? | **3 minutes. No kidding.** |
| 🆓 | Expensive plans? | **100% free and open source** |

</div>

<br/>

## 🚀 Quick Start

```bash
git clone https://github.com/PRGPU/FireWebCHAT.git
```

**Steps:**

1. 📁 Upload all files to your server (any shared hosting)
2. 🌐 Visit your domain — setup wizard auto-starts
3. ✅ Done in **3 minutes**

> 🔧 Need help? Use the setup helper → [firewebchat.vercel.app](https://firewebchat.vercel.app)  
> 🎬 Video guide → [youtu.be/Z_BUtrt-Trc](https://youtu.be/Z_BUtrt-Trc)
